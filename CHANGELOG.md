# Changelog

All notable changes to this repository are recorded here.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and
this repository adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- The house GitHub template, adopted from `ScaleMeNow/GITHUB-TEMPLATE` at
  `8a6c13b`:
  - `AGENTS.md` as the single contract for AI assistants, carrying the Arcade
    rules (strict CSP, page contract, pure game rules, supply-chain pins);
    `CLAUDE.md` and `.github/copilot-instructions.md` point at it.
  - `ci.yml` gains the `workflow syntax`, `template structure` and
    `screenshots` jobs beside the existing Arcade gates and the Pages deploy.
  - `.github/rulesets/main.example.json` requires the four template checks and
    the two Arcade gates; `scripts/apply-ruleset.sh` plans and applies it.
  - `.pre-commit-config.yaml` (gitleaks, actionlint, hygiene, screenshots, doc
    surface), `.github/gitleaks.toml`, the template `.gitignore`, and
    Dependabot for the `pre-commit` hook pins.
  - `wiki/` as the documentation surface, mirrored to the GitHub wiki by
    `.github/workflows/wiki.yml`, with the bundle map and ADRs.
  - Triage: `.github/labels.yml`, `.github/labeler.yml`, the label-sync and
    labeler workflows, a documentation issue form, and `SUPPORT.md`.
  - `dependency-review.yml` on pull requests that change dependency manifests.
  - The off-by-default bundles under `.github/bundles/`.
  - Screenshots of the home page and the four games in `docs/screenshots/`,
    regenerated by `npm run screenshots`.

### Changed

- `scripts/attribution-guard.sh` and its tests follow the template's current
  revision: commit records split on the unit separator, a failed title and body
  re-read is an error, and the test cases run without the runner's context.
- The idea issue form becomes the template's feature form, keeping the game
  picker; the bug form gains the template's reproduction and impact fields.
- The pull request template merges the template's checklist with the
  player-facing questions.
