# Support

Where to take a question, in the order that gets you an answer fastest.

## 1. Read the wiki

The [wiki](https://github.com/fschmutz/ARCADE-GAMES/wiki) is the source
of truth for how this repository works.
[Getting Started](https://github.com/fschmutz/ARCADE-GAMES/wiki/Getting-Started)
covers running the games locally and the repository setup, including the
non-obvious steps — the two manual steps the wiki sync needs, and why a ruleset
does not apply itself.

## 2. Search the issues

Including closed ones. Most "why does this not work" questions here have been
asked once already, and the answer is in the thread that closed it.

## 3. Open an issue

| You have                                            | Use                                                         |
| --------------------------------------------------- | ----------------------------------------------------------- |
| A game or page that does not work or looks broken   | [Bug report](../../issues/new?template=bug.yml)             |
| A new mode, a new game, or a way to make one better | [Feature request](../../issues/new?template=feature.yml)    |
| A wiki page or README that is wrong or unclear      | [Documentation problem](../../issues/new?template=docs.yml) |

Blank issues are disabled. The forms ask for the things a triager would have to
ask for anyway, and a filled form is usually answered the same day.

## Not here: security

**Never report a vulnerability in an issue.** Issues are readable by everyone
with access to this repository, which defeats the point of reporting privately.

Use the Security tab → _Report a vulnerability_, or email
<fschmutz@premaccess.com>. [SECURITY.md](SECURITY.md) has the full path and what
to expect.

The same goes for anything that is itself sensitive: a leaked credential, an
access grant that should not exist, a private repository that turned up
somewhere public. Email, do not file.

## Response expectations

This is a hobby project maintained alongside other work. There is no SLA. A
security report is acknowledged within two business days; anything else is
answered when an owner gets to it.

If something is blocking you right now, say so in the first line of the issue
rather than at the bottom.
